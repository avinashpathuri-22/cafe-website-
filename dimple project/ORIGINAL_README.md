# Cafe Guide

Cafe Guide is a luxury ocean-inspired cafe landing page built with HTML, CSS, and JavaScript. It features a premium beach-themed design, interactive menu browsing, reservation form, dark mode toggle, and multiple animations for a modern cafe experience.

## Overview

This project presents a stylish single-page cafe website for a coastal luxury brand called "Cafe Guide." The site includes:

- A hero section with ocean-inspired branding and call-to-action buttons
- About and feature sections highlighting the cafe experience
- A searchable and filterable menu with item cards and quantity controls
- Reservation booking form with guest/date selection
- Gallery and review sections
- Newsletter signup and contact information
- Dark mode support and responsive layout
- Smooth scrolling and scroll-based reveal animations

## Live Preview

## Features

- Responsive design for desktop, tablet, and mobile screens
- Luxury blue-and-sand color palette inspired by the ocean
- Search and category filters for menu items
- Add-to-cart-like quantity controls for menu items
- Reservation form with validation
- Floating decorative hero animations and scroll reveal effects
- Theme toggle for light and dark mode
- Animated counters and modern UI transitions

## Getting Started

1. Clone or download this project.
2. Open the project folder.
3. Launch `index.html` in your browser.

You do not need a build tool or package installation for this static website.

## Customization

You can customize the site by editing the content inside `index.html`:

- Update cafe name, tagline, and text content
- Replace menu items in the `menuData` array
- Modify colors and branding styles in the CSS section
- Adjust gallery images, testimonials, or offers
- Change reservation and contact details

## Notes

This is a static front-end project intended for design/demo purposes. It does not connect to a backend or database, so reservation and cart actions are front-end interactions only.
